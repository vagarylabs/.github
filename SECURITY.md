# Security policy

This policy covers every repository in the Vagary Labs organization that does not ship its own `SECURITY.md`.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately in either of these ways:

- On GitHub: use **Report a vulnerability** on the repository's **Security** tab (private vulnerability reporting).
- By email: [security@vagarylabs.com](mailto:security@vagarylabs.com).

We acknowledge reports within 48 hours and give an initial assessment within 5 business days. Good-faith research conducted under our policy will not be met with legal action. There is no paid bounty programme.

The full policy is at [vagarylabs.com/security](https://vagarylabs.com/security/), and the machine-readable contact is at [vagarylabs.com/.well-known/security.txt](https://vagarylabs.com/.well-known/security.txt).

## Supported versions

Unless a repository says otherwise, only the latest release or the default branch receives security fixes.
