# Vagary Labs

We build the platform that runs our own products.

Vagary Labs LLP designs, builds and operates one shared platform. Identity, speech, retrieval, billing and delivery run once, and every product consumes them: Index of News, Attorney Atlas, Vagary Voice, Vagaris and the rest of the fleet.

## Open source

Tooling we use, published:

- [bulk](https://github.com/vagarylabs/bulk): CSV-driven bulk HTTP and webhook runner with a thread-pooled send engine.
- [tldv_downloader](https://github.com/vagarylabs/tldv_downloader): fast tl;dv video downloader with N_m3u8DL-RE support.
- [pulseboard](https://github.com/vagarylabs/pulseboard): Android network-quality monitor, built for internal use and then opened up.
